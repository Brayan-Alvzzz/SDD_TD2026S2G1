  ### 2. Verificaciones Clave                                                           
                                                                                        
  • Aislamiento Multi-usuario: Se verificó que usuarios distintos pueden registrar      
  categorías con nombres idénticos (ej. "Personal") de manera completamente             
  independiente; ningún usuario puede consultar, asignar ni eliminar categorías ajenas  
  (respuestas 401/403/404).                                                             
  • Eliminación Segura sin Cascada ni Pérdida de Auditoría: Se comprobó que al eliminar 
  una categoría vía Web o API, el motor SQLite ejecuta ON DELETE SET NULL, desvinculando
  las tareas asociadas (category_id = None), las cuales permanecen activas en el sistema
  sin alteración de sus estados ni pérdida de sus registros históricos en audit_logs.
